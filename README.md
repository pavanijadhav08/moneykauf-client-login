# moneykauf-client-login
A modern and responsive Client Login System for the Moneykauf Fintech Project, featuring authentication UI and a Forgot Password workflow. This project is built using HTML, CSS, and JavaScript with a clean dark-themed UI.



## Features
- Client Login Interface
- Email & Password Authentication UI
- Show/Hide Password Toggle
-  Forgot Password Functionality
-  esponsive Design
- Modern Dark Theme UI
- Input fields for:
   - Name & Surname
   - Phone Number (with country code)
   - Currency Selection (From / To)
